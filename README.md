# stock-prediction-project
This project predicts stock prices using Machine Learning and LSTM. It includes technical indicators, candlestick charts, and a Buy/Sell recommendation system. The system also uses news sentiment analysis and evaluates accuracy using RMSE and MAE.

## 🚀 Overview
This project predicts stock prices using Machine Learning and LSTM. It analyzes historical data and provides insights like trends, charts, and recommendations.

## ✨ Features
- Stock Price Prediction (LSTM)
- Candlestick Charts
- Technical Indicators (RSI, Moving Average)
- Buy/Sell Recommendation
- News Sentiment Analysis
- Accuracy Metrics (RMSE, MAE)

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- TensorFlow / Keras
- Flask
- SQLite
